Selected Web Apps

Some Web MIDI and Web Audio apps that I like. You find many more here.

General Purpose

  • OpenDAW: An Open Source DAW. Works on Mac and iPad. Hint: On iPad, connect a bluetooth mouse. Use ... menu on instrument track, then Capture MIDI / Click to Access external Devices.
  • Signal Midi Editor: An Open Source Midi Editor. Hint: In the web page select one or more MIDI inputs in Settings/MIDI. Then a "Record" button appears.

Note Visualizations (Web MIDI input)

  • Dot Piano: Shows dots for played notes. Hint: Enable input port before loading the page!

Special shaped Keyboards (Web MIDI output)

Practical Music Theory!
  • WebMIDICon: An interesting collection of touch interfaces with MIDI Ouput. Hint: After you switch between different instruments, reload the page.
  • Chromatone: A web site about music theory and colors. Comes with an interesting collection of touch interfaces with MIDI Input and Ouput. Examples: Keys, Circle of Fifths and MIDI Utilities. Hint: Allow Sysex in settings, otherwise MIDI does not work. If you use the app's onscreen keyboard, you may sometimes want to enable sound from the keyboard's settings menu.
  • The Tonnetz: One Key - Many Representations. Modified version with MIDI Input and Output and without Audio. Hint: MIDI Output is sent to the first available output port and connects once a note is to be sent.
  • The Tonnetz (original): MIDI Input and Audio Ouput. Hint: Turn down built-in sounds if you are just interested in the visual output.
  • aQWERTYon: Play notes and chords using your computer keyboard. Sends MIDI out. Hint: Connects to output ports when starting to type on the physical computer keyboard. Inspired the computer keyboard input mode that you can activate in the bottom right of the app (next to the Onscreen Keyboard). Computer keyboard mode is affected by the Root and Scale settings of the Onscreen Keyboard to make it easy to play in tune.

Music Theory (General)

  • La La Lab: the Mathematics of Music: A collection of educational music web apps. No Web MIDI interface, but in the spirit of Web MIDI (notes, not sounds). It would be great to add Web MIDI support to some of the apps.
