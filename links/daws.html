Web DAWs

Tested DAWs:

  • OpenDAW: supports MIDI input and output. WebCLAP audio plugins only work in Web Midi Connect on macOS, not on iPhone or iPad. We work on a solution.
  • BandLab: Supports MIDI input.
  • Soundtrap: Supports MIDI input.

DAWs, that do not work in Web Midi Connect:

  • Audiosauna: Opens in Safari, but does not open in Web Midi Connect.
  • AudioTool: supports MIDI input. Only works in Chrome, not in Safari and not in Web Midi Connect.

Untested DAWs and special tools:

  • Soundation: Should support MIDI input.
  • Amped Studio
  • Veena Studio
  • FL Studio Web
  • ButtonBass DAW
  • Smol Sequencer
  • Grid Sound
  • Propeller
  • Harmonicon: Source code. Must be self-hosted.
